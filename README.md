# TUI Production Control

Sistema interno de controle de produção e estoque 
de scooters elétricas — TUI Motors.

## Tecnologias
- Python Flask
- PostgreSQL (NOVIDADE)
- JavaScript

## Funcionalidades
- Controle de estoque de scooters e peças
- Sistema de pedidos com prioridade
- Painel de metas por setor

## Planejamento
- Rastreabilidade das etapas de montagem
- Atribuição de ID único para cada scooter que inicia montagem
- Automação no controle de entrada e saída de peças conforme montagem.
